# Week 1 - Frontend Web Developer Internship

## Project Title

DevPortfolio - Responsive Frontend Developer Portfolio

## About the Project

This project was developed as part of Week 1 of my Frontend Web Developer Internship.

The objective of the task was to transform a wireframe concept into a functional static web page using HTML and CSS.

As no specific wireframe was provided with the task, a custom wireframe was planned and designed based on the given requirements. The design was then converted into a responsive static webpage.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- Git
- GitHub

## Website Sections

The webpage contains:

- Header and Navigation
- Hero Section
- About Me
- Skills
- Projects
- Contact
- Footer

## Responsive Design

The website was designed to work across desktop, tablet and mobile screen sizes.

CSS media queries were used to adjust the layout, navigation, typography, cards and content according to the screen width.

## Key Learning Outcomes

This task helped me understand semantic HTML, CSS styling, Flexbox, CSS Grid, responsive design, media queries, Git and GitHub.
